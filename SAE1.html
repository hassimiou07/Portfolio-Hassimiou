Installation Debian 13 et IntelliJ IDEA

Linux · environnement de développement

Vue d'ensemble

Évaluation pratique : installer et configurer un environnement de développement complet sur une machine virtuelle Debian 13 avec le bureau KDE Plasma. Installation et validation du JDK, de Git et d'IntelliJ IDEA par trois méthodes différentes (archive, snap, flatpak).

Format : travail individuel de 3 heures, avec des captures d'écran qui documentent chaque étape d'installation et de validation, déposées sur Chamilo.

Installation du système

  1. 1

    Vérification SHA-512

    Empreinte de référence du site officiel Debian comparée à l'empreinte locale calculée avec sha512sum.

  2. 2

    Création de l'utilisateur

    Écran de l'installateur Debian qui demande le nom de login.

  3. 3

    Bureau KDE Plasma

    Bureau en 1440x900 avec un terminal qui affiche le login et le résultat de kinfo.

  4. 4

    Accès root

    Validation de la commande sudo -i, avec accès administrateur.

Outils de développement

  1. 1

    Git

    Vérification de la version de Git (2.47.3), en root puis en utilisateur.

  2. 2

    JDK et archive d'IntelliJ

    Installation du JDK avec apt (OpenJDK 21), vérifiée avec java -version, puis extraction de l'archive d'IntelliJ IDEA.

  3. 3

    Méthode 1 : archive

    Lancement d'IntelliJ IDEA depuis l'archive extraite, et relevé de l'espace disque occupé.

  4. 4

    Méthode 2 : snap

    Installation de snap avec apt, puis de intellij-idea-community avec snap, vérifiée avec snap list.

  5. 5

    Méthode 3 : flatpak

    Lancement d'IntelliJ IDEA Community avec flatpak, et relevé de l'espace disque occupé.

  6. 6

    Espace disque

    Relevé df : la partition racine est remplie à 97 % une fois les trois installations faites. Le coût en espace disque est un critère de choix entre les méthodes.
